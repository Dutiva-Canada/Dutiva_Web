# Dutiva Canada Inc. — HR Document Package

Complete set of hiring, policy, and offboarding documents for Dutiva Canada Inc.,
an Ontario workplace. Each document exists as an English (`*.en.md`) and a French
(`*.fr.md`) file with matching clause structure — issue whichever the employee
works in, and keep both versions in the employee file.

> **Before issuing:** these are working templates drafted for an Ontario,
> non-federally-regulated employer. Have employment counsel confirm the final
> wording for each person's situation before signature — particularly the
> termination clause in `02-employment-agreement` and the status analysis in
> `03-contractor-agreement`. Nothing here is legal advice.

## Using these in Dutiva Documents

Each file is a single document: a `#` title, numbered sections, and blank
fill-in lines like `[Employee name]`. To import into the workspace, paste the
body of a single language version into a new document — keep the section
numbering so generated copies stay consistent with this source.
